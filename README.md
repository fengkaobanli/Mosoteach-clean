# Mosoteach-clean 辅助工具

## 项目简介

Mosoteach-clean 辅助工具是一个为云班课平台设计的自动化工具，旨在帮助用户更高效地管理和学习平台上的课程资源。该工具支持自动刷课和题库导出功能，为用户提供便捷的学习体验。

## 功能特点

- **自动登录**：支持使用账号密码自动登录云班课平台
- **资源识别**：智能识别音频、视频和其他类型的资源
- **自动刷课**：支持自动刷音频和视频资源，节省学习时间
- **题库导出**：支持导出班课中的测验题目，可自定义输出格式

## 安装步骤

### 前提条件

- Python 3.6 或更高版本
- pip 包管理工具

### 使用方法

```bash
# 下载项目代码
git clone https://github.com/fengkaobanli/Mosoteach-clean.git

# 进入项目目录
cd Mosoteach-clean

# 安装依赖
pip install requests parsel

# 运行主程序
python main.py
```

## 功能说明

### 1. 刷资源功能

登录后选择 `1` 进入刷资源模式：
- 支持刷整个班课的所有资源
- 支持选择特定资源组和单个资源
- 支持视频、音频、文档等多种资源类型

### 2. 题库导出功能

登录后选择 `2` 进入题库导出模式：

#### 支持的题型
- 单选题 `[单选题]`
- 多选题 `[多选题]`
- 判断题 `[判断题]`
- 填空题 `[填空题]`

#### 自定义格式语法

格式字符串使用以下占位符：
- `t` = 题目
- `x` = 选项
- `d` = 答案
- `n` = 换行

相邻重复的占位符会自动去重。

#### 格式示例

| 格式 | 效果 |
|------|------|
| `tnx xnd` | 题目/选项/答案（三行，默认格式） |
| `tnxnd` | 题目/选项/答案（三行） |
| `t x d` | 题目 选项 答案（一行） |
| `txnxd` | 题目选项/选项答案（两行） |

#### 导出参数

- `all` - 导出所有活动
- `1 3 5` - 导出第1、3、5个活动
- `-link` - 将所有题目合并到一个文件

#### 使用示例

```
# 导出所有活动（默认格式）
all

# 导出所有活动（自定义格式）
all tnx xnd

# 导出所有活动并合并到一个文件
all tnx xnd -link

# 导出第1、3个活动
1 3

# 导出第1、3个活动（一行格式）
1 3 t x d
```

#### 输出格式

单选题示例：
```
1. [单选题] 中国特色社会主义事业总体布局是（ ）。
A."四个全面" B."十个明确" C."五位一体" D."一国两制"
答案:C
```

多选题示例：
```
2. [多选题] 下列属于春季的月份是？
A.一月 B.三月 C.四月 D.十二月
参考答案：BC
```

判断题示例：
```
3. [判断题] 治国理政只需要法律作为重要手段。
答案:错
```

填空题示例：
```
4. [填空题] 生活过得好不好， ______ 最有发言权。
参考答案：人民群众
```
